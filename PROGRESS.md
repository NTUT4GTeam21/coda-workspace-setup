## Known issues

- Expanded volunteer guide is a learning draft; SADeaf must review it and confirm the safeguarding contact and private reporting procedure before sessions.

- Sign-up now needs a code for volunteers and staff (viewers need none). Existing accounts are unaffected; staff create codes on the Admin page.
- 16 word cards have possible SgSL matches (variant entries) that staff must review on the Admin page or in the word editor (was 20 on 2 Nov).
- All 21 AI-drafted stories are now approved (16 Nov); any new draft stays hidden until staff check its story text, word cards and prompts and approve it. External book links remain optional.
- `npm run lint` still reports Prettier formatting errors in the auto-generated `src/integrations/` files, which are left untouched on purpose. Hand-edited files are clean.
- The shared sign-up codes ADMIN and VOLUNTEER are reusable and are named in a public migration file; staff should cancel them on the Admin page before real use.
- Child registration remains staff-controlled; confirm parental consent and a volunteer referral process before widening permissions.
